# UNSIA Library Frontend

Antarmuka React, Vite, dan TypeScript untuk UNSIA Digital Library.

## Persyaratan

- Node.js 24 atau lebih baru

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Aplikasi tersedia pada `http://localhost:5173` secara default.

## Verifikasi

```bash
npm run lint
npm run format:check
npm test
npm run build
```

Fondasi UI telah mencakup Tailwind CSS, dashboard Chart.js, layout responsif, tema terang/gelap, serta Bahasa Indonesia dan Inggris melalui i18next.
